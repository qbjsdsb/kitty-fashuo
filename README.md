# Kitty 法硕上岸小屋

法硕（法学）考研复习工作台 · Hello Kitty 风格 · 单文件零依赖

## 功能

- 考研倒计时 + 学习打卡（8 周热力图）
- 目标分数卡（默认参考复旦 2026 法硕法学实录 362 分）
- **五科考点清单（311 个核心考点，科→章→考点三层组织，逐点标记掌握）**
- 刷题记录（法学卷五类题型 + 14 天正确率折线 + 答题时钟）
- 错题夹（错因分布 + 3 星掌握度 + 3 天重做提醒）
- 卷种开关（法学 / 非法学）

## 使用说明

- 数据全部存储在浏览器 localStorage，不经过任何服务器
- 建议每周使用页面底部「导出备份」保存一份 JSON
- 换设备时用「导入恢复」即可带走全部数据
- 考试日期、目标分数均可自定义

## 技术

单文件 HTML，全部 CSS/JS/SVG 内联，零外部依赖，离线可用。
